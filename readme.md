# TeamFinder

Веб-платформа, где разработчики и дизайнеры находят команду для совместной работы над pet-проектами.

## Реализованный вариант

**Вариант 3** — навыки проектов и фильтрация по ним.

## Стек

- Python 3.12, Django 6.0
- PostgreSQL 16
- Docker, Docker Compose
- Pillow

## Быстрый старт

**Необходимо:** Docker Desktop и Git.

```bash
git clone <ссылка на репозиторий>
cd team-finder-ad
cp .env_example .env
docker-compose up --build
```

После запуска открой http://localhost:8000

При старте контейнер автоматически применит миграции, соберёт статику и наполнит базу тестовыми данными.

```bash
docker-compose exec web python manage.py createsuperuser
```

Админка: http://localhost:8000/admin/

## Что умеет проект

- Регистрация и вход по email
- Список проектов на главной с пагинацией (12 на страницу)
- Фильтрация проектов по навыкам
- Создание, редактирование и завершение проектов
- Добавление навыков к проекту с автодополнением
- Список пользователей с пагинацией
- Редактирование профиля, смена пароля
- Автоматическая генерация аватарки при регистрации
- Кнопка «Присоединиться к проекту»
